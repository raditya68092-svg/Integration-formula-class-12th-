1. Integration की Basic जानकारी

∫ f(x) dx = F(x) + C
यदि F′(x) = f(x), तो ∫ f(x) dx = F(x) + C
∫ k f(x) dx = k ∫ f(x) dx
∫ [f(x) ± g(x)] dx = ∫f(x)dx ± ∫g(x)dx

C = Integration constant (समाकलन स्थिरांक)।

2. Algebraic Formulas

∫ dx = x + C
∫ xⁿ dx = xⁿ⁺¹/(n+1) + C, n ≠ −1
∫ dx/x = ln|x| + C
∫ (ax+b)ⁿ dx = (ax+b)ⁿ⁺¹/[a(n+1)] + C
∫ dx/(ax+b) = (1/a) ln|ax+b| + C
∫ eˣ dx = eˣ + C
∫ aˣ dx = aˣ/ln(a) + C, a>0, a≠1
∫ ln x dx = x ln x − x + C

3. Trigonometric Formulas

∫ sin x dx = −cos x + C
∫ cos x dx = sin x + C
∫ sec²x dx = tan x + C
∫ cosec²x dx = −cot x + C
∫ sec x tan x dx = sec x + C
∫ cosec x cot x dx = −cosec x + C
∫ tan x dx = ln|sec x| + C
∫ cot x dx = ln|sin x| + C
∫ sec x dx = ln|sec x + tan x| + C
∫ cosec x dx = ln|cosec x − cot x| + C
∫ tan²x dx = tan x − x + C
∫ cot²x dx = −cot x − x + C
∫ sin²x dx = x/2 − sin 2x/4 + C
∫ cos²x dx = x/2 + sin 2x/4 + C

4. Inverse Trigonometric Type

∫ dx/√(a²−x²) = sin⁻¹(x/a) + C
∫ dx/(a²+x²) = (1/a) tan⁻¹(x/a) + C
∫ dx/(a²−x²) = (1/2a) ln|(a+x)/(a−x)| + C
∫ dx/[x√(x²−a²)] = (1/a) sec⁻¹(|x|/a) + C
∫ dx/√(x²+a²) = ln|x+√(x²+a²)| + C
∫ dx/√(x²−a²) = ln|x+√(x²−a²)| + C

जहाँ लागू हो, a > 0 और denominator शून्य नहीं होना चाहिए।

5. Special Forms

∫ f′(x)/f(x) dx = ln|f(x)| + C
∫ f′(x)[f(x)]ⁿ dx = [f(x)]ⁿ⁺¹/(n+1) + C, n ≠ −1
∫ eᶠ⁽ˣ⁾ f′(x) dx = eᶠ⁽ˣ⁾ + C
∫ f′(x)/[1+f(x)²] dx = tan⁻¹(f(x)) + C
∫ f′(x)/√(1−f(x)²) dx = sin⁻¹(f(x)) + C

6. Integration by Parts

∫ u dv = uv − ∫ v du

u चुनने के लिए ILATE नियम उपयोगी है: Inverse trigonometric, Logarithmic, Algebraic, Trigonometric, Exponential.

7. Substitution Method

यदि t = g(x), तो dt = g′(x) dx
∫ f(g(x)) g′(x) dx = ∫ f(t) dt
∫ 2x(x²+1)⁵ dx = (x²+1)⁶/6 + C

8. Partial Fractions

1/[(x+a)(x+b)] = A/(x+a) + B/(x+b)
1/[x(x+1)] = 1/x − 1/(x+1)
∫ dx/[x(x+1)] = ln|x| − ln|x+1| + C
∫ dx/[(x+a)(x+b)] = [ln|x+a| − ln|x+b|]/(b−a) + C

9. Definite Integration

∫ₐᵇ f(x) dx = F(b) − F(a)
∫ₐᵃ f(x) dx = 0
∫ₐᵇ f(x) dx = −∫ᵦᵃ f(x) dx
∫ₐᵇ f(x) dx = ∫ₐᶜ f(x) dx + ∫꜀ᵇ f(x) dx
∫₀ᵃ f(x) dx = ∫₀ᵃ f(a−x) dx
∫₋ₐᵃ f(x) dx = 2∫₀ᵃ f(x) dx, यदि f even हो
∫₋ₐᵃ f(x) dx = 0, यदि f odd हो

10. Definite Integration के महत्वपूर्ण नियम

∫₀ᵃ f(x) dx = ∫₀ᵃ f(a−x) dx
∫₀²ᵃ f(x) dx = ∫₀ᵃ [f(x)+f(2a−x)] dx
∫₀ᵃ f(x) dx = (1/2)∫₀ᵃ [f(x)+f(a−x)] dx
